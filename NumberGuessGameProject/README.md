# 🎯 Number Guessing Game (Java)

## 📌 Description
This is a simple Java console-based game where the user guesses a randomly generated number.

## 🚀 Features
- Difficulty levels (Easy, Medium, Hard)
- Random number generation
- Hints (Too High / Too Low)
- Tracks number of attempts
- Replay option

## 🛠️ Technologies Used
- Java
- JDK
- VS Code

## ▶️ How to Run
1. Compile:
   javac NumberGuessGame.java

2. Run:
   java NumberGuessGame
