# 🔐 Password Strength Checker (Modified Version)

## 📌 Description  
This is an enhanced (modified) version of a basic password checker.

## 🚀 Features Added  
- Password strength analysis (Weak / Medium / Strong)  
- Common password detection  
- Password suggestions for weak passwords  
- Improved validation using regex  

## 🛠 Tech Used  
- Java  

## ▶️ How to Run  
1. Compile: javac Main.java  
2. Run: java Main
