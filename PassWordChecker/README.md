# Password Strength Checker

This is a simple Java project that checks the strength of a password.

## Features
- Checks minimum length (8 characters)
- Checks uppercase letters
- Checks lowercase letters
- Checks numbers
- Checks special characters
- Displays result: Weak / Medium / Strong

## Technologies Used
- Java

## How to Run
1. Compile the program:
   javac PasswordChecker.java
2. Run the program:
   java PasswordChecker
3. Enter a password and check its strength
